# Customer Lifetime Value Prediction

## Overview

This project is a Machine Learning application that predicts Customer Lifetime Value (CLV) using customer-related data. The model helps businesses estimate the long-term value of customers, enabling better marketing strategies and customer retention.

## Features

- Customer Lifetime Value Prediction
- Data Preprocessing
- Machine Learning Model
- Interactive Prediction Interface
- Fast and Accurate Predictions

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Joblib
- Streamlit/Flask (depending on deployment)
- Jupyter Notebook

```bash

```

```bash

```

```bash
python pro1.py
```
